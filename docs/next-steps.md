# 后续工作

技术实验已完成。首先应读懂现有结果：按同一形状、精度和计时协议查看两个 L4 会话的一致性，解释为什么有些融合案例收益明显，而 Transformer 或普通调用仍退化。硬件计数器只支持它实际测量的案例，不能把合理猜测当作已证实的瓶颈。

随后整理方法贡献与论证边界，准备开题/论文材料所需的相关工作、对照依据和局限。现有近邻筛选是实验方法，不能直接声称新算法或全面优于成熟库。A100 目前只有一个已验收会话，限定的项目安全检查也不代表完整厂商库已无告警。

若写作暴露出具体证据缺口，再针对该问题补实验，例如增加特定形状的重复测量或验证某个资源瓶颈；当前没有必须扩大的既定 GPU 任务。修改内核、精度、依赖或配置后需另立版本并重新验证，保留旧策略与旧结论。

日常维护继续使用项目独立 uv 环境。原始数据做独立备份；GitHub 负责代码分享，不能代替私有实验归档。公开前后持续检查敏感信息，并单独决定本项目的使用许可。
