# 数据与历史版本的可用性

分享仓库包含算子源码、测试、依赖锁文件、实验配置、冻结策略及文档中的性能摘要。原始 ZIP/CSV、profiler trace、完整工具日志、带输出 notebook、账号信息和本机路径不随分享快照上传。

本地工作区的 `storage/runs/triton/` 保存已经验收的完整证据。项目内 `local-data/downloads/` 只整理浏览器下载的副本，并保存文件哈希及对应归档位置。两者都属于本地数据；快照中的证据链接统一指向本说明，避免展示无法访问的私人链接。

GitHub 快照使用新提交历史，未携带本地作者邮箱、机器身份及旧文档中的私人信息。文中历史提交号和策略中的训练来源标识用于关联本地原始归档，不代表这些旧提交可直接从 GitHub 检出。历史完成审计需要本地原始源码 bundle、manifest 和实验数据；仅克隆分享仓库不能重建这些历史证据。

当前源码可以在 NVIDIA Linux 主机按锁定依赖重新运行。新实验必须记录自身版本、GPU 和计时协议，不能将其结果替代已验收的历史记录。性能摘要保留加速、退化及限定的安全检查范围；未公开原始数据时，读者无法仅凭摘要独立核验历史性能值。

目前没有为本项目新增开源许可证。公开可见性与使用授权应分别处理；第三方教程来源及已有许可声明见 [sources.md](sources.md)。
